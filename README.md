# Cyclistic Bike-Share Analysis

## Project Overview

This project analyzes Cyclistic bike-share usage to explore differences between annual members and casual riders. The goal is to identify usage patterns and develop data-informed recommendations that could help convert casual riders into annual members.

## Business Question

How do annual members and casual riders use Cyclistic bikes differently, and how could these differences inform membership marketing strategies?

## Tools Used

- **Python** — data cleaning, analysis, and calculations
- **Google Colab** — Python notebook environment
- **Pandas** — data manipulation and analysis
- **Matplotlib** — data visualization
- **GitHub** — project documentation and portfolio hosting

## Dataset

The analysis covers October 2025 through September 2026. The project uses historical Cyclistic bike-share trip data. The original data source, applicable license, and any data limitations should be reviewed before reuse.

## Key Findings

- **6,166,346 rides** were included in the final analysis.
- Annual members accounted for approximately **64.6%** of rides, while casual riders accounted for **35.4%**.
- Casual riders had a longer average ride duration than members: **17.56 minutes versus 11.92 minutes**.
- Members completed approximately **76.73%** of their rides on weekdays.
- Casual riders completed approximately **37.3%** of their rides on weekends, compared with approximately **23.27%** for members.

## Recommendations

1. Explore marketing campaigns aimed at casual riders during periods when they are most active.
2. Communicate the value of annual membership using verified pricing, benefits, and customer research.
3. Test targeted campaigns and measure membership conversion rates before expanding them.
4. Compare results across different customer segments and time periods to refine marketing strategies.
